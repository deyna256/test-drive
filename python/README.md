# test-drive-skill

The Python helpers for [Test Drive](https://github.com/deyna256/test-drive), an agent skill for
testing web user journeys and creating reports with recordings. The `test-drive` command checks
scenario file structure, selects or sets up `agent-browser`, and renders HTML reports.

The package requires Python 3.10 or newer and has no third-party Python runtime dependencies.
Browser testing also requires `agent-browser` and Chrome or Chromium. Recording WebM video requires
FFmpeg with the `libvpx` encoder. Install the agent skill separately; see the
[project README](https://github.com/deyna256/test-drive#readme) for setup and usage.
